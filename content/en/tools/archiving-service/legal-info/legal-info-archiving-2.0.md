# Archive Service 2.0 third-party software notices and licence information

The third-party software notices and license information for the Archive Service 2.0 tools (the command-line tool and the client library) can be found as part of the [Corda 4.12.13 release]({{< relref "../../../platform/corda/4.12/enterprise/legal-info/legal-info-4.12.13.html" >}}).

The Archive Service CorDapp runs inside the Corda node and uses the libraries the node provides, so its third-party software notices and license information are those of the Corda Enterprise version the node runs. See the legal information of that release.
The few libraries the CorDapp bundles itself are included in the Corda 4.12.13 release page above.
