Package com.r3.corda.networkmanage.common.cryptoservice.azurekeyvault

Class AzureKeyVaultMsalCryptoServiceTest

  • All Implemented Interfaces:
    
public final class AzureKeyVaultMsalCryptoServiceTest
extends CryptoServiceSpec<AzureKeyVaultCredentials, AzureKeyVaultKeyConfig>

    These tests need to be run manually. They require an Amazon KeyVault (and the associated service principal) to be set up and will perform operations that are not free of charge.

    Refer to https://docs.microsoft.com/en-gb/azure/key-vault/

    This can be done using the scripts available under the resources folder. The only pre-requisites are:

    • Install the azure CLI and execute az login (See: https://docs.microsoft.com/en-us/cli/azure/install-azure-cli)

    • Install jq (See: https://stedolan.github.io/jq)

    To execute the tests:

    • Navigate to resources/hsm-setup/azure and execute setup_resources_msal.sh, which creates all the necessary Azure resources and resource files for the tests below.

    • Run the tests.

    • Once finished, navigate to resources/hsm-setup/azure and execute tear_down_resources_msal.sh, which removes all the previously created Azure resources and local resource files.
