class AzureKeyVaultMsalCryptoService(keyVaultUrl: String, protection: <Error class: unknown class>) : BaseAzureKeyVaultCryptoService

Implementation of a CryptoService that is backed by an Azure Key Vault cloud HSM via MSAL (Microsoft Authentication Library).

Uses the Azure KeyVault Java API https://docs.microsoft.com/en-us/java/api/overview/azure/keyvault.
