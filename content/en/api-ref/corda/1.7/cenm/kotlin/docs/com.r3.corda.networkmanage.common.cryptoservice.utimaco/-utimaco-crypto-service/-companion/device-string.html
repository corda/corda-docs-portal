deviceString

fun deviceString(host: String, port: Int, additionalHosts: List<String> = emptyList()): String

Builds the value of the CryptoServerProviderConfig.Device setting: a space-separated list of "

$port@$

host" entries.

With more than one entry the driver works in cluster mode and reconnects on its own after the connection to the HSM is lost, while with a single entry every call fails from then on, until the process is restarted.

Without additionalHosts the same address is listed twice, as in previous releases. Older drivers (e.g. 1.67) treat this as a cluster of two devices and so reconnect. Newer drivers (e.g. 6.3.0) de-duplicate the entries (ignoring case), so they do not reconnect, and in cluster mode they also report a key that does not exist as a cluster error (B90C0103) instead of not finding it. With newer drivers additionalHosts should hold a different address of the HSM (e.g. its IP address next to its host name) or of other HSMs of the same cluster, for the driver to reconnect.

Throws

IllegalArgumentException

if additionalHosts is used and an address is blank or repeated.
