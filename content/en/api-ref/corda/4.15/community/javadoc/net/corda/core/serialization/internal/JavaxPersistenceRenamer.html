Package net.corda.core.serialization.internal

Object JavaxPersistenceRenamer

  • All Implemented Interfaces:
    
public class JavaxPersistenceRenamer

    Renames the references a class makes to the javax.persistence API (Corda 4.14 and earlier) to jakarta.persistence (Corda 4.15, Hibernate 7), for the classes AttachmentsClassLoader loads from attachments. Only jakarta.persistence is on the classpath of a Corda 4.15 node and of its external verifier, so a class of a contract attachment built for an earlier version that refers to a javax.persistence type in its code (rather than in annotations alone, which the JVM drops if their types are missing) would fail to link, and the transaction with it.

    This is the rename alone, and the one implementation of it: the node's CorDapp class loader converts the CorDapps it maps to the database with JavaxPersistenceTransformer (node-api), which makes this rename and converts the Hibernate annotations on top (rename's decorate arguments). The Hibernate annotations of an attachment's class are left as they are, as nothing maps the classes of an attachment class loader to a database.
