RPCClient

class RPCClient<I : RPCOps>(transport: ERROR CLASS: Symbol not found for TransportConfiguration, rpcConfiguration: CordaRPCClientConfiguration = CordaRPCClientConfiguration.DEFAULT, serializationContext: SerializationContext = SerializationDefaults.RPC_CLIENT_CONTEXT, haPoolTransportConfigurations: List<ERROR CLASS: Symbol not found for TransportConfiguration> = emptyList(), useGlobalThreadPools: Boolean = false)

RPCClient is meant to run outside of Corda Node JVM and provide connectivity to a node using RPC protocol. Since Corda Node can expose multiple RPC interfaces, it is possible to specify which RPCOps interface should be used.

When haAddressPool RPCClient will perform connectivity failover using parameters specified by CordaRPCClientConfiguration. Whenever status of connection changes registered RPCConnectionListener will be informed about those events.
